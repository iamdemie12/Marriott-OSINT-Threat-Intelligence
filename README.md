# Marriott International — OSINT & Threat Intelligence Investigation

## Project Overview
An independent, educational Open-Source Intelligence (OSINT) investigation examining Marriott International's publicly observable digital footprint and potential cybersecurity risks.

The project combines passive reconnaissance, infrastructure analysis, threat actor profiling, and defensive security recommendations.

**Analyst:** Peace Akinwale  
**Investigation Type:** Passive OSINT / Threat Intelligence  
**Target Organisation:** Marriott International

## Project Objectives
- Research Marriott International's public digital footprint.
- Identify publicly indexed documents, domains, and authentication portals.
- Examine publicly available DNS and infrastructure information.
- Visualise relationships between digital entities.
- Compare hospitality-related threat actors using MITRE ATT&CK.
- Recommend practical defensive security measures.

## Tools and Techniques
- **Google Dorking:** Public document and web presence discovery.
- **theHarvester:** Domain and subdomain intelligence gathering.
- **Shodan:** Analysis of publicly indexed network services.
- **Maltego:** Digital infrastructure relationship mapping.
- **Kali Linux / nslookup:** DNS investigation and validation.
- **MITRE ATT&CK Navigator:** Threat actor TTP analysis.

## Investigation Findings
The investigation documented publicly indexed Marriott-related web resources, DNS observations, third-party infrastructure indicators, and relationships visualised through Maltego.

The report also compares **Darkhotel**, associated with espionage-focused activity, and **FIN5**, associated with financially motivated intrusions affecting hospitality and payment environments.

Findings are historical observations and do not independently establish vulnerabilities, system ownership, or current exposure.

## Security Recommendations
- Segment guest and internal networks.
- Strengthen phishing prevention and staff awareness.
- Enforce multi-factor authentication.
- Improve payment-system security.
- Deploy endpoint monitoring and centralised logging.
- Maintain tested incident response procedures.
